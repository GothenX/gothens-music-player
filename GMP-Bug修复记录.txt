Gothen's Music Player —— Bug 与修复记录
（自融合 Dango music 底座以来的每一个问题、原因与修法；按批次排列）

作者：Gothen
当前版本：0.2.4-beta

================================================================

【早期音频输出问题（0.1.x ~ 0.2.1，融合前的自研阶段，记录在此备查）】

1. 进界面直接崩溃
   IllegalStateException: Can only blur once per frame
   原因：26.2 的 Screen 已经自动调用过一次 extractBackground（含模糊），子类又调了一次。
   修复：删掉子类里的调用，改用普通半透明遮罩。

2. 真机（Android + FCL）完全无法播放
   NoSuchMethodError: javax.sound.sampled.AudioSystem.getSourceDataLine
   原因：FCL 的精简 JDK 移除了 Java Sound 的输出实现（解码链路本身正常）。
   修复：换输出层。

3. 换成自建 OpenAL 上下文后，听到的是游戏原版音效
   日志：Stop: Invalid name parameter / Allocate new source: Invalid name parameter
   原因：该环境 OpenAL 上下文是全局的，自建并切换后游戏的声音引擎 source/buffer 名字全部失效。
   修复：不再创建设备/上下文，反射复用游戏的 Library.currentDevice/context，只创建自己的 source/buffer，绝不销毁或切换游戏上下文。

4. 完全没声音，日志没有任何报错
   原因：预缓冲按「时间」等 180ms，但 OpenAL 只有 4 个缓冲槽（MP3 一块仅约 26ms，4 块也到不了 180ms），写线程第 5 次写入永久等待空闲缓冲，互相死等。
   修复：预缓冲改为按缓冲个数（排 2 块即起播），并加「4 块排满仍未播放就强制 alSourcePlay」兜底。

5. 依旧无声（0.1.6 后）
   原因：用 AL_BUFFERS_QUEUED 判断是否该起播，该 OpenSL 后端返回 0，永远不调用 alSourcePlay。
   修复：不再用任何 OpenAL 查询决定起播；每写入一块 PCM，只要 source 不是 PLAYING 就 alSourcePlay。

6. 按 N 切歌后彻底没声
   原因：切歌时用 AL_BUFFERS_QUEUED 决定 unqueue 数量，查询返回 0，旧缓冲没被卸下，新歌入队全部失败。
   修复：切歌/拖进度/停止直接销毁并重建 source 与 buffer，不依赖 unqueue 查询；暂停/恢复改用内部标记；音频线程整体加异常兜底。

7. 曲库只加载 27 首（放了 100 多首）
   原因：只扫描「当前游戏运行目录」下的 music；开启版本隔离时游戏目录是 .minecraft/versions/<版本>/，而玩家把歌放在 .minecraft/music/。
   修复：多目录合并扫描去重（游戏目录/music、.minecraft/music、游戏目录上一级/music）；界面显示实际扫描到的目录；滚轮在整个面板内都能滚动。

8. 一放就「重置」、每首只响 2 秒
   原因：上一版加的「2 秒没释放缓冲就判卡死」依赖不可靠的 AL 查询，把正常播放误判成卡死；且 source 没关距离衰减，增益被衰减到几乎听不见。
   修复：关闭距离衰减（AL_ROLLOFF_FACTOR=0、位置 0,0,0）；查询不可用时改用「按每块预计播完时间轮换」；去掉 2 秒判死；加播放日志。

9. 仍然无声：日志 state=4114 但 pos 几乎不动
   原因：该设备 OpenSL 后端根本不消费流式队列（入队缓冲一块都不播），而游戏自带音效是一次性静态缓冲所以正常。
   修复：放弃流式队列，改为整段解码进内存 + 单个静态缓冲播放；进度由播放时钟推算；拖动进度从目标帧重新解码并重建缓冲。

10. 原版背景音乐和播放器叠着响
    原因：只调 MusicManager.stopPlaying()，部分场景原版音乐仍会响。
    修复：每 tick 把 SoundEngine 里 MUSIC 的运行时增益写 0 并停掉当前那首，不改 options.txt；播放器停止后恢复 MUSIC 音量。方块/走路/怪物/UI 音效不受影响。

11. 拖动进度响应慢（约 3 秒）
    原因：每次 seek 都重新打开解码流并从文件头丢弃到目标帧。
    修复：整首 PCM 首次播放时解码一次并缓存，拖动只做内存切片 + 重新上传静态缓冲，毫秒级生效。

12. 歌放不出来（分段推进时期，多批反复）
    原因：用播放状态查询推进分段，OpenSL 上查询抖动，导致整首被瞬间跳完只剩静音。
    修复：改回「整段解码 + 一次性静态缓冲」（最早确认能出声的路径），只有超过 64MB 的超长曲子才走分段，且分段按片段时长推进。

13. 开界面卡到几帧
    原因：圆角/描边逐像素画三角，单块面板约 800 次绘制；封面色块每帧重算；文字每帧重复裁剪测量。
    修复：圆角改「每行一段」（单块降到约 40 次）；封面色块 24×24 → 12×12；文字裁剪缓存。

14. 换成 owo-ui 后版式不对（整批回滚）
    修复：撤回整体换 owo-ui 的改动，恢复霓虹玻璃版式；owo-lib 改为仅编译期可选，不再是运行前置。

【融合 DangoMusic 之后的问题】

15. 专用服务器上把 jar 丢进去什么都不发生
    原因：fabric.mod.json 的 environment 是 client，服务端不注册通道。
    修复：环境改为 *，新增 server 入口 GothenMusicServer。

16. 本地 FLAC 放不了
    IllegalArgumentException: FLAC input exceeds download limit
    原因：解码器沿用了网络下载的 64 MB 上限，高解析 FLAC 动辄上百 MB 直接被拒。
    修复：上限按堆大小放开（最高 900 MB），文件太大时提示写出实际大小；声道支持从 1-2 放宽到 1-8，5.1 自动混成立体声。

17. 多声道 FLAC 只有前两轨有声音
    原因：只写前两条轨，其余声道静默丢失。
    修复：按实际声道数交错输出；双声道的 left/side、mid/side 还原单独处理。

18. 服务器曲目没有歌词、没有封面
    原因：SERVER 音源的 lyrics 直接返回空；封面也一直是空。
    修复：按「歌手 歌名」联网找最匹配的歌词与封面；服务器目录里有同名图片时，客户端真的向服务端要这张图并缓存到 config/gmp/cache/server/cover/；只读服务端图片、超过 512 KB 不发、webp 视为没有。

19. 服务器封面「servercover:」标记客户端不认识（等于没图）
    修复：客户端识别该标记，向服务端请求图片并落盘缓存，下次直接读。

20. 服务器歌名带上「分类目录 ·」前缀，导致联网搜歌搜不到
    修复：搜索时只用服务端给的原始歌手与歌名，去掉目录前缀。歌词结果内存缓存 10 分钟。

21. 本地存档里也出现了「服务器音乐」音源
    修复：新增联机检测 Platform.onServer（世界已加载 + 有网络连接 + 不是本地存档/局域网），只有真的在别人服务器里才出现；退出服务器自动退回网易云，下次进服自动切回。

22. 挂机计时被打回 0，永远进不了电影模式
    修复：修正计时逻辑，输入才重置。

23. 自研相机接管导致右边破面、区块没加载
    原因：相机被瞬移到远处，地形视锥没跟上。
    修复：整套自研相机删除，改为内嵌官方 Ambient Camera 1.1.0，由它处理镜头、转场、避墙与 HUD 隐藏。

24. 开了黑边歌词但游戏里看不到
    原因：Ambient Camera 默认隐藏原版 HUD，而 26.x 的 HUD 是先离屏收集、最后由 Hud 统一提交，HUD 被隐藏后 GMP 的黑边层永远提交不出去。
    修复：让 Ambient Camera 不隐藏 HUD（HIDE_HUD=false，由 GMP 接管），并让 GMP 自己的 mixin 单独取消准星与快捷栏/状态图标，聊天栏与计分板保留。

25. 电影镜头设置写不进去
    原因：加载顺序导致覆盖。
    修复：同步改成先读 Ambient Camera 当前值再写，GMP 设置优先于它自带配置页；HIDE_HUD、原生黑边一起锁 false，避免两边打架。

26. 电影镜头掉帧
    原因：每帧反射读写 Ambient Camera 的 8 个配置项；它的「生物对焦」每帧扫附近实体。
    修复：配置每秒同步一次；关掉 ENABLE_MOB_FOCUS；帧率上限设为不限。

27. 贴墙时出现穿墙镜头
    修复：强制 ALLOW_WALL_CLIPPING=false，机位沿射线检测避开方块。

28. 大厅播放卡片完全不显示（第一次）
    原因：卡片绘制的入口被「当前有歌在放」这个条件挡住，一进游戏还没点播放（或没有播放记录）就整张卡不画。
    修复：去掉 active 条件，没歌时显示空卡（封面占位 + 标题 + 「No track playing」+ 打开播放器按钮）。

29. 大厅卡片仍然不显示（第二次，真凶）
    原因：主菜单卡片是两段式提交——beforeGui 里先画到贴图（screenLayer.render），再由 ScreenMixin 在原版画 TitleScreen 时提交（screenLayer.submit）；两段都卡在「有歌在放」上。
    修复：两段都不再看播放状态，大厅永远有这张卡。

30. 灵动岛与 Jade 的物品信息卡叠在一起（并曾被推到屏幕中间）
    原因：为了避让 Jade，灵动岛按 GUI 像素下移 76，手机端 guiScale 很大，被放大成小半屏。
    修复：让位量按屏高封顶（最多 14%）；后续直接改成可调位置（Island X / Island Y），不再自动硬挪。

31. 大厅卡片封面空白，要按 M 打开播放器再退出才显示
    原因：主菜单只在「取」封面，没有把下载好的图上传成纹理；上传只在游戏 HUD / 播放器界面里被别处调用。
    修复：大厅卡片每帧调用 CoverCache.upload()，进大厅直接显示封面。

32. 大厅卡片看上去是一块黑板
    原因：大厅没有世界画面，液态玻璃只能采到黑底。
    修复：改成半透明面板（30% 深色 + 白色描边 + 轻阴影），直接透出大厅背景。

33. 拖 Card X / Card Y 时界面不变透明（预览不触发）
    原因：用字符串 key 判断拖的是哪一项，key 对不上就永远不触发。
    修复：改成按 FloatValue 对象比较（isCardPosition / isPositionValue）。

34. 调 HUD 位置时看不到小地图与 Jade
    原因：原版在打开任何界面时都会隐藏整个游戏 HUD（Jade、小地图一起消失），所以设置页里怎么透明都看不到它们。
    修复：预览改成「界面让开、只画目标 HUD」，并增加「打开聊天栏直接拖动」的摆位方式——那时 HUD 全部可见，松手自动写回位置。

35. 左上角「封面 + 歌名 + 歌手」与 Mem/FPS 调试文字重叠
    原因：原卡片固定画在 (6,6)，与客户端的内存/FPS 文字同一块区域。
    修复：先挪位、再整体删除该卡片（含主菜单里调它的地方、跳动小柱子、封面加载分支与对应设置项）。

36. 游戏内左侧播放卡片反复被要求「不要」
    修复：删除该卡片实现与「歌曲卡片（Song card）」模块注册及设置组，游戏内只保留顶部灵动岛。

37. 侧栏 Local 音源显示「登录」且名称是英文
    修复：本地/服务器曲库不画头像与登录按钮，改显示「本地曲库」；补中文音源名。

38. 界面仍出现 DANGO 品牌
    修复：侧栏标题改 GOTHEN MUSIC，代码里再无 Dango 字样（README 里的旧环境变量名不影响界面）。

39. 更新检查可能指向旧仓库发布页
    原因：先问一起听中转，中转数据是旧的。
    修复：改为先直连自己仓库的 latest release，连不上 GitHub 才用中转兜底。

40. 模组图标带黑底、资料页简介过时
    修复：抠掉框外框内的黑色背景（透明 PNG 256×256）；简介换成中英新版（由Gothen再制…）。
