Gothen's Music Player —— 功能更新一览
（自融合 Dango music 底座以来新增/改造的功能，按批次排列；只写功能，不写修 bug）

作者：Gothen
适配：Minecraft 26.2 / Fabric
当前版本：0.2.4-beta

================================================================

【一、底座与命名】
1. 以 DangoMusic（Sorihiko/DangoMusic）为底座，保留它已经跑通的一整套：液态玻璃播放器界面、3D 歌词、Dynamic Island（灵动岛）、歌曲卡片、一起听。
2. 全工程迁到自己的命名空间：模组 id 改为 gmp，名称 Gothen's Music Player，作者 Gothen，主页 GothenX/gothens-music-player；包名 me.sorihiko.dango → com.gothen.gmp，资源 assets/dangomusic → assets/gmp，配置目录 config/dangomusic → config/gmp。
3. 保留 GPL-3.0 许可与原作者的版权声明。

【二、多音源】
4. 音源扩展为 5 个：网易云、QQ 音乐、酷狗、本地、服务器音乐；侧栏可切换，音源名支持中文（本地 / 网易云 / QQ音乐 / 酷狗 / 服务器音乐）。
5. 新增「Local 本地」音源：扫描 config/gmp/local 与游戏目录下的 music 文件夹，支持 mp3 / flac / ogg-vorbis；文件名写成「歌手 - 歌名」会自动拆出歌手；同目录同名 .lrc 自动加载歌词。
6. 新增「服务器音乐」音源：服务端递归扫描 /home/container/music，支持「流行 / 纯音乐」这类分类子目录，分类名显示在歌名前面；一首歌所有人共用一份，不用各自拷贝。
7. 服务器曲库走模组自己的 gmp:music 通道（曲库列表用文字包，音频按 256 KB 分块下发，不开额外端口），客户端预取 4 块边收边存，并在 config/gmp/cache/server/ 做本机缓存，同一首歌不重复占用服务器流量。
8. 在线刷新：切到服务器音源、打开服务器歌单、点侧栏「刷新」都会让服务端重扫目录，新上传的歌不用重启服务器。
9. 服务器音源只在「真的在别人服务器里」时出现：世界已加载 + 有网络连接 + 不是本地存档（含开局域网），退出服务器自动退回网易云，下次进服自动切回。
10. 本地歌的歌词与封面改为「先本地后网络」：同名 .lrc / 同名 jpg、png、webp 优先，没有才按「歌手 歌名」联网匹配。

【三、一起听】
11. 一起听升级为「群组」模式：建群时设群名 + 密码（可留空），同服务器的人输入群名密码即可加入，不再是一串随机房间码。
12. 群名直接决定房间标识（群名摘要），同名群唯一、重名被拒，不需要服务器提供群列表接口。
13. 群主可随时开关「允许成员控制播放」：关着时只有群主能切歌/拖动进度/暂停，打开后谁都能操作，以最后一次操作为准。
14. 群内文字聊天：只走模组自己的同步通道，不进服务器公屏，界面保留最近 40 条。
15. 群组页整页改造：群名输入、密码输入（圆点显示）、创建/加入按钮、成员列表（群主 HOST 标记）、群聊面板与发送框，中英文案齐全。
16. 服务器权限同步：成员只能写自己发的聊天条目，房间名/密码只有群主能改；云端（Firebase）模式的规则文件同步加了 name / pwd / chat 读写规则。
17. 群组一起听支持服务器曲目：全组按同一相对路径各自去服务器拉歌。

【四、播放与曲库】
18. 收藏功能：五个音源的歌都能收藏，存 config/gmp/favorites.json，重开游戏还在；播放栏红心对所有音源显示；侧栏「正在播放」下新增「收藏」页。
19. 播放队列与进度续播：正在放时每 5 秒、切歌/暂停/拖进度/停止时各记一次（config/gmp/playback.json）；下次进游戏约 3 秒后恢复上次的队列、第几首、第几秒、音量、随机/单曲循环，状态是暂停，按播放从原秒数继续。
20. 主菜单（大厅）播放卡片：封面、歌名、歌手或状态消息、红心、上一首/播放暂停/下一首、可点击的底部细进度；按 1280×800 布局再整体缩放，不同分辨率与 GUI 缩放下手感一致，点击会先被 GMP 接住，不会误触「单人游戏」等按钮；没歌时是「打开播放器」的空卡。
21. 大厅卡片（0.2.4 后期）改成半透明面板，直接透出大厅背景；封面每帧推进下载与上传，进大厅即显示。

【五、电影镜头（Cinematic）】
22. 内嵌官方 Ambient Camera 1.1.0（Modrinth 26.2 Fabric，MIT），fabric.mod.json 用 "jars" 声明，装 GMP 就自带，不用另放 jar。
23. 挂机自动接管相机：键盘鼠标 15 秒（可调）没动就进入电影镜头，镜头依次环绕人物（半径 5.5）、升到 7 格高俯拍、侧后方 120°，每个镜头 12 秒（可调）。
24. 电影黑边 + 黑边歌词：进入时上下压黑边（高度可调），底部黑边滚动当前歌词与翻译（字号可调），同时藏掉准星和快捷栏。
25. 任何输入（转视角、动鼠标、点按键、走路）立刻退出电影镜头，相机回到自己的视角。
26. 设置页新增「Camera」标签（Cinematic camera 组）：开关、自动开始秒数、每个镜头时长、黑边歌词开关、歌词字号、黑边高度，改动即时同步并保存到 Ambient Camera。
27. 电影镜头默认开启，默认挂机 15 秒启动；黑边与歌词由 GMP 画（Ambient Camera 原生黑边关掉，避免叠两层）。

【六、HUD 与界面】
28. HUD 区域协调（HudZones）：用类名探测 Jade / WTHIT / Hwyla / The One Probe 与小地图模组（Xaero / JourneyMap / VoxelMap），不依赖编译期接口，装没装都不报错。
29. 灵动岛（屏幕正上方胶囊）显示正在播放：封面 + 歌名 + 跳动音浪；切歌/暂停会展开成大卡片（封面、歌名、歌手、进度条），有新版本时也在里面提醒。
30. 灵动岛位置可调：设置里 Island X / Island Y（0～1 百分比），默认 0.5 / 0.02 就是正上方居中；打开聊天栏可以直接拖动它，松手自动保存。
31. 电影镜头整层接管 HUD：在原版 HUD 收集的唯一公共出口只交出 GMP 自己的那一层（上下黑边 + 歌词），其余全部拦掉——Jade 的物品卡、小地图、血量甲具、聊天、计分板都不会出现在电影画面里。
32. 侧栏账号区：本地曲库 / 服务器曲库不显示头像和「登录」（这两个音源没有账号概念），显示「本地曲库」。
33. 品牌与文案：侧栏标题改成 GOTHEN MUSIC，界面里不再出现旧品牌 DANGO。
34. 更新检查指向自己的仓库：优先直接查 github.com/GothenX/gothens-music-player 的 latest release，连不上 GitHub 才用一起听中转兜底。
35. 游戏内不再画 GMP 播放卡片（原左侧大卡片、「歌曲卡片」模块一并移除），游戏内只保留顶部灵动岛。
36. 模组资料页：换成像素风收音机图标（透明底 256×256）、名称 Gothen's Music Player、作者 Gothen；简介为「由Gothen再制的游戏内音乐播放器…」并附英文。
