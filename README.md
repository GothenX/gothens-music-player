# Gothen's Music Player

**Minecraft 26.2 (Fabric) 的游戏内音乐播放器 —— 由 Gothen 再制，基于 Dango music。**

液态玻璃界面、多音乐平台、3D 歌词、本地高品质音乐播放、更方便的一起听、自动电影镜头……更多功能，敬请期待。

## 这是什么

GMP 是一个**客户端**模组：按 `M` 在游戏里打开一个液态玻璃风格的播放器，边玩边听歌。它不替换游戏音频引擎，而是复用游戏已经初始化好的 OpenAL 设备，单独创建自己的 source/buffer 播放，所以**关掉播放器、关掉游戏音效都不影响听歌**，方块、脚步、怪物、UI 音效也完全不受影响。

界面在屏幕上的形态只有两种：

- **灵动岛**：屏幕正上方的小胶囊，显示封面 + 歌名 + 跳动音浪，切歌/暂停时会展开成大卡片，有新版本时也会在里面提醒。
- **主菜单播放卡片**：在大厅（标题界面）显示，没歌时是「打开播放器」的空卡，有歌时是完整控制器（封面、歌名、歌手、收藏、上一首 / 播放暂停 / 下一首、可点击进度条）。

游戏内不再有左侧那一坨播放卡片——只想安静听歌的时候，画面上只留一颗小胶囊。

## 安装

1. 装好 **Fabric Loader** 与 **Fabric API**（Minecraft 26.2）。
2. 把 `gmp-0.2.4-beta+26.2-fabric.jar` 放进 `mods/`。
3. 完成。电影镜头所需的 **Ambient Camera 1.1.0 已经内嵌在 jar 里**（`fabric.mod.json` 用 `jars` 声明，MIT 许可），不需要另外下载。

> 专用服务器也可以装这个 jar（`environment: *`），用来提供「服务器音乐」曲库。

## 音源

| 音源 | 说明 |
|---|---|
| 网易云 | 默认音源，搜索 / 歌单 / 封面歌词。需要登录态时把 cookie 放到 `config/gmp/netease_cookie.txt` |
| QQ音乐 | 平台音源，与网易云并列可切换 |
| 酷狗 | 平台音源 |
| 本地 | 扫描 `config/gmp/local` 与游戏目录下的 `music/`，支持 mp3 / flac / ogg |
| 服务器音乐 | 只在真的进入别人的服务器时出现；曲库由服务端扫描 `/home/container/music` 提供 |

侧栏可以随时切音源；本地 / 服务器曲库不显示登录，因为没有账号概念。

## 本地音乐怎么放

把歌丢进下面任意一个目录（会合并扫描并去重）：

```
.minecraft/config/gmp/local/
.minecraft/music/
<游戏目录>/music/            ← 开版本隔离时也能扫到
```

- 支持 **mp3 / flac / ogg-vorbis**，FLAC 支持 16~24bit、最高 192kHz、1~8 声道（5.1 会自动混成立体声）。
- 文件名写成 `歌手 - 歌名.mp3` 会自动拆出歌手。
- 同目录放一个同名 `.lrc` 就自动加载歌词；同名 `jpg / png / webp` 会自动当封面。
- 本地没有歌词/封面时会自动按「歌手 歌名」联网匹配。

## 服务器音乐（多人一起听）

1. 服务端装同一个 jar（外加 Fabric API），把歌放进 `/home/container/music`，可以建 `流行/`、`纯音乐/` 这种分类子目录，分类名会显示在歌名前面。
2. 客户端切到「服务器音乐」，就能看到服务端曲库；音频按 256 KB 分块走 MC 自己的连接下发，不开额外端口。
3. 听过的歌会缓存到 `config/gmp/cache/server/`，同一首歌再听直接读本地，不重复占用服务器流量。
4. 服务端新增歌曲后，切到服务器音源 / 打开服务器歌单 / 点侧栏「刷新」都会重扫，不用重启服务器。

## 一起听（群组）

- 建群时设**群名 + 密码**（密码可空），同服务器的人输入群名密码就能加入；群名直接决定房间标识，同名群唯一。
- 群主可开关「允许成员控制播放」：关着时只有群主能切歌 / 拖进度 / 暂停。
- 群内文字聊天只走模组自己的通道，不进服务器公屏，保留最近 40 条。
- 一起听支持服务器曲目：全组按同一个相对路径各自去服务端拉歌，谁都不用本地有文件。

## 电影镜头（Cinematic）

挂机自动接管相机：键盘鼠标 **15 秒**（可调）没动就进入电影模式，镜头依次环绕人物、升到 7 格高俯拍、侧后方 120°，每个镜头 12 秒（可调）。

- 进入时上下压出电影黑边，同时藏掉准星与快捷栏，底部黑边里滚动当前歌词（有翻译时附在下面）。
- 任何输入（转视角、动鼠标、点按键、走路）立刻退出，相机回到自己的视角。
- 设置页「Camera」标签可以调：开关、自动开始秒数、每个镜头时长、黑边歌词开关、歌词字号、黑边高度。

## 设置与数据

按 `M` 打开播放器，侧栏「设置」里能调音源、歌词、灵动岛位置、电影镜头等。

| 文件 | 内容 |
|---|---|
| `config/gmp/` | 主配置目录 |
| `config/gmp/favorites.json` | 收藏 |
| `config/gmp/playback.json` | 播放队列与进度（下次进游戏从原处续播，状态为暂停） |
| `config/gmp/cache/server/` | 服务器歌曲与封面缓存 |
| `config/gmp/netease_cookie.txt` | 网易云登录态（可选） |

**灵动岛位置**：设置里 `Island X` / `Island Y`（0～1，默认 0.5 / 0.02 = 正上方居中）。想看着小地图、Jade 一起摆位，就在游戏里打开聊天栏直接拖灵动岛，松手自动保存。

## 常见问题

**Q：只有画面没有声音？**
A：先确认游戏本身有声音（音量不是 0）；GMP 复用游戏的音频设备，如果设备初始化失败，说明这台设备的音频后端不支持，换个启动器/JDK 版本再试。

**Q：放自己的歌时原版背景音乐还在响？**
A：GMP 播放时会把 MUSIC 通道的运行时增益写 0 并停掉当前那首，不改 `options.txt`；停止播放后自动恢复。

**Q：长曲子只放十几秒？**
A：已修复（分段解码按片段时长推进），若仍出现请附上 `[GMP]` 开头的日志行。

**Q：服务器音乐看不到？**
A：它只在真的进入别人的服务器（世界已加载 + 有网络 + 不是本地存档/局域网）时出现；同时确认服务端装的是同一个 jar。

**Q：界面里还有 Dango 的痕迹？**
A：界面品牌已全部改为 GOTHEN MUSIC；模组 id 为 `gmp`，代码在 `com.gothen.gmp` 下，仅许可证与版权声明保留原作者。
